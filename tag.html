SEMANTIC ELEMENTS

Semantic elements are html elements that have a meaning and purpose in the html documents they are used to give meaning to the content of the html documents and they are used to improve the accesibility on the html document example of semantic elements are <header> <article> <footer> <aside>

semantic elements desriptions
<header> header is an html tag which is used at the top of the html code which is is not visible to the web page user
<article> article are those texts which are displayed on a specific part on the body
<footer> footer is used for the bottom part of a web page
<aside> aside is used for seperating group of texts taking to a different position on the screen

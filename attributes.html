Examples of html Attributes

  • CLASS : class is a html attributes used to add a css naming and it can take one or more names by adding space in between,the naming are important and it is used to target one or more html elements for styling

  • ID:it is used as an identifier in html elements to single handedly target one particular element to be referenced to in css for styling or javascript for functions.

  • STYLE: style is an html elment attributes used to pass inline css directly into html elements

  • TYPE: type is an input tag attribute used to specify input field type functionalities e.g type="text" this makes __input fields to act as text field

    • TEXT: text is used to instruct html input fields to accept only text characters from a user

    • NUMBER: Number is used to instruct html input field to accept only numbers from a user

    • DATE: A date is used to instruct html input fields to accept only date format from a user

    • PASSWORD: Password is used to instruct html input fields to accept only password and to obscure the input character from user by replacing it with dot

    • BUTTON: Button is used to indtruct input fields to act as a button element

    • COLOR: Color is used to instruct html input fields to display as color picker

    • EMAIL: Email is used to instruct html input fields to accept only valid email format e.g; Timi@gmail.com

    • FILE: file is used to instruct html input field to enable user to be able to select file from their device or computer

    • IMAGE: Image is used to instruct html input field to enable user to be able to select or upload a picture

    • CHECK BOX: check is used to instruct html input field to enable a user to toggle a small box

    • RADIO: Radio is used to instruct html input field to enable a user to switch between to or more small circle

    • SUBMIT: Submit is used to instruct html input field to submit a form and as well check if the form input field is actually a valid
